Static Analysis for Personal Data

Open Bachelor's thesis · Static analysis, Data protection

Motivation

Ensuring that software systems, especially web applications, comply with privacy requirements is a complex and critical challenge. On the one hand, it is complex because laws, such as the GDPR [1], impose strict requirements on how organizations handle (personal) data but offer limited guidance on concrete technical solutions. On the other hand, it is critical because failing to comply with these requirements can result in substantial financial penalties.

When analyzing a software system, it is important to know precisely where personal data resides and how it flows through the system. For the large body of existing applications, this information is not documented but is embedded implicitly in the source code. Locating personal data manually across a codebase is tedious, error-prone, and does not scale, which makes automated support highly desirable.

References
