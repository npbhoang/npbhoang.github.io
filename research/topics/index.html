Model-driven Privacy

Model-driven privacy (MDP) is a software development methodology in which privacy requirements are specified as models and enforcement mechanisms are generated automatically via model transformations. A developer writes three interconnected declarative models, i.e., a data model describing the state space, a security model capturing fine-grained access control, and a privacy model expressing data-protection requirements. The methodology generates a web application that is security- and privacy-aware by design.

Enforcing Fine-grained Access Control on Data-centric Applications

Fine-grained access control (FGAC) policies are policies that authorization decisions based not only on a user's role and the data they are permitted to act on, but also on contextual conditions that may depend on the current state of the application. Enforcing such policies in data-centric applications is challenging becauese access control rules are often manually implemented and scattered across the codebase, making them error-prone and difficult to maintain. To address this challenge, we aim to make FGAC policies explicit and enforce them systematically at the data layer, e.g., by rewriting SQL queries or intercepting the object-relational mapper so that personal data never leaves the database unchecked.
