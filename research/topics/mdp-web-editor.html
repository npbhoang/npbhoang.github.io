A Web-based Code Editor for Model-driven Privacy

Open Bachelor's thesis · Software engineering, Data protection

Motivation

Model-driven privacy [2] (MDP) is a software development methodology in which privacy requirements are specified as models, and enforcement mechanisms are generated automatically via model transformations. MDP enables developers to specify three interconnected declarative models: a data model describing the state space of the system, a security model capturing fine-grained access control requirements, and a privacy model expressing data protection requirements. From these models, the methodology automatically generates a web application together with enforcement mechanisms that make it security- and privacy-aware by design.

The authors of the aforementioned paper have built and published the tool, called νActionGUI [4], which implements this methodology and generates web applications using the Flask [1] (Python) framework. However, the models are currently written as plain text files, and the tool is run from the command line. Developers, therefore, receive little support while writing the models: there is no syntax highlighting, no code completion, and errors, e.g., a reference to an undefined entity in the security model, are reported only when the generator is run. Moreover, getting started requires a local installation of the tool, which is a barrier for newcomers and for teaching. Modern code editors address these problems with language-aware features, which can be provided in the browser, e.g., with the Monaco editor.
